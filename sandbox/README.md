# Sandbox

Spikes: throwaway experiments, each its own tiny Godot project in `sandbox/<topic>/`, that learn how one system
behaves before a game depends on it. The product of a spike is its findings page in `docs/godot/<topic>.md` (numbers,
captures, what to do and what to avoid); the code stays here as a record and is never moved into a game as it is.
Which systems need a spike: the **spike** rows of `docs/godot/index.md`.
