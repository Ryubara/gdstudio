# Security

## What counts

Report anything that lets untrusted input harm a person using GDStudio, for example:

- a downloaded tool or asset that is unpacked or run without its pinned hash being checked;
- an unsafe default, such as a network service listening without being asked to;
- a flaw in the build, CI or release process that could ship tampered artifacts.

Ordinary bugs go in a normal issue.

## How to report

Use GitHub's private vulnerability reporting: the repository's **Security** tab, then **Report a vulnerability**.
Please do not open a public issue for it.

Please give a way to reproduce the problem and say which version you used. We aim to answer within
7 days.
