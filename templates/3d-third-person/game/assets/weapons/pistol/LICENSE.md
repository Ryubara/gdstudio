# Pistol

- Model: a generic 1911-type pistol with no maker's marks, GDStudio's own work, built by script
- Source: Deadnight's service pistol, <https://github.com/Ryubara/deadnight> (`tools/blender/weapon_specs/service_pistol.py`
  with `tools/blender/build_weapons.py` and `tools/blender/weaponlib.py`, Deadnight #797, commit `d304d1a9`); studied
  from public photos for shape and proportion only (Deadnight's `docs/research/weapon-models.md` lists them)
- Author: GDStudio contributors
- Licence: MIT, the same as Deadnight and this kit (<https://opensource.org/license/mit>)
- Files: `pistol.glb` and its palette `pistol_weapons_palette.png`, built by `build_pistol.py` (Deadnight's builder and
  spec copied whole, the origin moved to the grip); `pistol_held.tscn`, the hold on the mannequin's hand.

No third-party file is in this folder.
