# Rifle

- Model: a generic carbine with a carry handle (an M4A1 type) with no maker's marks, GDStudio's own work, built by
  script
- Source: Deadnight's M4A1, <https://github.com/Ryubara/deadnight> (`tools/blender/weapon_specs/m4a1.py` with
  `tools/blender/build_weapons.py` and `tools/blender/weaponlib.py`, Deadnight #795, added in commit `62fa30dd`);
  studied from public photos for shape and proportion only (Deadnight's `docs/research/weapon-models.md` lists them)
- Author: GDStudio contributors
- Licence: MIT, the same as Deadnight and this kit (<https://opensource.org/license/mit>)
- Files: `rifle.glb`, `rifle_far.glb` and their palettes `rifle_weapons_palette.png` and
  `rifle_far_weapons_palette.png`, built by `build_rifle.py` (Deadnight's builder and spec copied whole, the origin
  moved to the grip, the left hand's support moved 4 cm back); `rifle.tscn`, the two levels in one scene.

No third-party file is in this folder.
