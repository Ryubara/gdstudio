# Prototype mannequins

GDStudio's own prototype bodies (kit #1149), generated by the scripts in this folder: no file here is downloaded.

| File | What it is |
| --- | --- |
| `<look>_<body>.glb` | a body (`male`, `female`, `chibi`) in a look (`form`, `joint`, `facet`): the armature and `Body_LOD0`, `Body_LOD1`, `Body_LOD2` |
| `mannequin_import.gd` | the import script of every model: the hips' `motion_scale`, the twist modifier, the levels of detail by distance |
| `mannequin_twist.gd` | `MannequinTwist`, the modifier that turns the twist bones |
| `bodies.py`, `styles.py`, `shapes.py`, `skeleton.py` | a body's numbers, a look's rules, the skin, the skeleton |
| `build_mannequins.py` | builds every file with the pinned Blender; a rebuild writes the same bytes |
| `render_mannequins.py` | review sheets: turntables, wireframes, the rig, poses and clip frames |
| `rig_<body>.json`, `report.json` | each body's whole rest pose; triangles, vertices, bones and bytes of each file |

## Using one

Drag a `.glb` onto the character's `Model` slot in place of the model there (the template's steps for replacing the
model). Both Universal Animation Library files play on every body. Attach to a socket bone by name with a
`BoneAttachment3D`: `socket_hand_r`, `socket_hand_l`, `socket_back`, `socket_hip_l`, `socket_hip_r`, `socket_head`,
`socket_camera`. Recolour a body by giving its material another 32 px palette (nine cells: main, panel, joint, left,
right, visor, palm, sole, chest mark).

The template's default character is still the Quaternius mannequin: the pistol's hold, the ragdoll and the hit zones
are measured on its skin.

## Making your own body

Copy a body in `bodies.py`, change its numbers (keep the leg's proportions: one `leg` scale), add it to `BODIES` and
run `build_mannequins.py -- --body <name>`. The build fails before it keeps a file whose rest is not the library's,
whose levels are over budget, whose feet are off the floor or whose weights are wrong. Then run
`tools/mannequin/measure_bodies.gd` with the new file in its list.

The skeleton keeps the bone names, parents and rest rotations of Quaternius's Universal Animation Library rig (CC0),
which is what lets its clips play here unchanged; the rest is the kit page `docs/tools/blender/mannequin-rig.md`.
