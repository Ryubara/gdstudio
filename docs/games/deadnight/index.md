# Deadnight

Deadnight is GDStudio's first game: a round-based co-op zombie survival game over one night at a 1958 drive-in
theater, made with Godot for the browser. Its own repository
([Ryubara/deadnight](https://github.com/Ryubara/deadnight)) keeps its design, research and lessons, and its own docs
site. The summary, how we build it, its design philosophy and its conventions join this folder with gdstudio #770.
