# Games

One folder per GDStudio game, `games/<game>/`: what the game is, how we build it, its design philosophy and its own
conventions, so an agent new to it can start from one page. Each game keeps its own repository and docs site for the
day-to-day detail (designs, research, measurements); the folder here is the summary that links to them.

**Belongs here:** a game's summary, how it is built, its design philosophy and conventions, and reviews of it that the
next game learns from. **Not here:** what any game would reuse, which goes to its topic (`gamedev/`, `engines/`,
`tools/`, `studio/`).
