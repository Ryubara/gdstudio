# The corrections log

The rows of [What the maintainer caught](../maintainer-corrections.md), one page per kind, split when the single page
reached the size limit (gdstudio #1115). Each row says what was pointed out in our words, with its source (the date it
was recorded, the game, and the issue or pull request), and links the topic section it updated in its last cell. A row
never quotes the maintainer: the checks fail a row with a cell that starts with a quotation mark, and a row whose last
cell links no section, on every page here.

- [Corrections and the checks they become](corrections.md): what the maintainer corrected or added that neither the
  coordinator nor any agent had proposed first.
- [Found by playing](found-by-playing.md): concepts and details the maintainer found by playing a build.
- [Done wrong first](caught-by-checks.md): mistakes a test, a measurement or a review caught first.

Keep each page under 40 KB; when one fills up, split it by date or subject into another page here and list it above.
