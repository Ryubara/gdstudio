# What the maintainer caught

A log of what the maintainer corrected or added that neither the coordinator nor any agent had proposed first, from
Deadnight's first nights of work onward, and of what our own checks caught us doing wrong. Each line says what was
pointed out in our words, with its source (the date it was recorded, the game, and the issue or pull request), and
links the topic section it updated: the entry (the approach, what to watch out for, where it was seen) is kept in
the topic page an agent reads for that work, not here ([Learning in the topic pages](rules.md), gdstudio #769).

A new correction updates its topic section and adds one row to the log page of its kind, in the same pull request. A
task agent updates the section and puts the row in its report; the coordinator adds it to the log, so many agents never
edit one page. A prompt is never quoted, word for word or nearly, here or anywhere in a public repository: the checks
fail a row with a cell that starts with a quotation mark, and a row whose last cell links no section (gdstudio #780).

The rows live in [the corrections log](corrections-log/index.md), one page per kind, since the page reached the size
limit (gdstudio #1115, [Page size](rules.md#size)). Add a row to the page of its kind; the checks read every page of
the folder the same way.
