# Tools

The programs outside the engine that make a game's assets, one folder each, run as the workspace pins them
(`gds tool path <tool>`, `tools.toml`). Today that is [Blender](blender/index.md).

**Belongs here:** how to model, rig, animate, texture, bake and export in a tool, with the scripts that repeat it.
**Not here:** how the engine imports and uses the result (`engines/<engine>/`), and the studio's own command-line tools
(`gds`, the hooks), which are in `studio/`.

Another tool gets `tools/<name>/` with its own `index.md` once a page about it is written, never an empty stub.
