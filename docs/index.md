# GDStudio

GDStudio makes original games with Godot and Blender, built by agents. This site is the **global docs hub**: what
every GDStudio game shares. Each game keeps its own docs site for what is particular to it.

## What lives here

| Section | What it covers |
| --- | --- |
| [Godot](godot/index.md) | The Godot systems we rely on, what we know, and which need a spike first. |
| [Blender](blender/index.md) | Cleaning and exporting assets with the pinned Blender. |
| [Audio](audio/index.md) | Making sound assets outside the engine: voice lines with ElevenLabs. |
| [Lessons](lessons/index.md) | Problems we hit and how we solved them: search here first. |
| [Workspace](workspace.md) | The folder layout, the bootstrap, and the pinned Godot and Blender. |
| [Agents](agents.md) | The roster, their models, and the loop from issue to merged pull request. |
| [Starting work](starting-work.md) | Issues start oldest first, through `gds issue start`; how the window works. |
| [Hooks](hooks.md) | What the hook dispatcher refuses while agents work, and the proof gate. |
| [Research](research/index.md) | How we build games with agents, and how to repeat it on another engine. |
| [References](refs.md) | Fetching third-party models into `refs/` with their licences. |

More sections join as their tooling lands: the style bible, the asset and audio pipelines, the scenario harness,
the hooks and agent rules, engine and tool guides, and the log of problems solved.
