# GDStudio

GDStudio makes original games with Godot and Blender, built by agents. This site is the **global docs hub**: what
every GDStudio game shares. Each game keeps its own docs site for what is particular to it.

## Where things are

The site is laid out by topic, so a page about cameras sits beside the other camera pages whichever game or tool
taught it. [Docs site](studio/docs-site.md) has the folder map and the rules for where a new page goes.

| Section | What it covers |
| --- | --- |
| [Game development](gamedev/index.md) | Principles that hold in any engine: level design, audio and the rest of the craft. |
| [Engines](engines/index.md) | One folder per engine a game uses; today [Godot](engines/godot/index.md). |
| [Tools](tools/index.md) | The programs outside the engine that make assets; today [Blender](tools/blender/index.md). |
| [Studio](studio/index.md) | How the studio works: agents, starting work, hooks, the workspace, captures, sync. |
| [Games](games/index.md) | One folder per game: what it is and how we build it. |
| [Lessons](lessons/index.md) | The old record, one file per problem, until #770 moves it into the topic sections. |
