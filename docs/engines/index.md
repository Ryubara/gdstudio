# Engines

One folder per engine a GDStudio game is built with: the engine's systems we rely on, what we measured about each, and
its traps. Today that is [Godot](godot/index.md), the engine of every game so far.

**Belongs here:** how an engine does something (its API, renderer, physics, export, test runner) and what it costs.
**Not here:** the principle behind it, which holds in any engine (`gamedev/`), and one game's numbers (the game's docs).

Another engine gets `engines/<name>/` with its own `index.md` when a game needs it, never an empty stub ahead of that.
